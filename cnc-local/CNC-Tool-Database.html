Back up & move settings

Settings and materials save in this browser on this computer. Download an updated HTML copy to take them with you, or export a JSON backup to restore later. Imports replace current settings, libraries, tool inventory, raw sheets, notes, and the cut list.

A copy opened in a fresh browser uses admin / Feds201. Additional admin passwords stay with this browser and are not included in data exports.

Admin passwords

All passwords use the username admin. The fallback password admin is always enabled and cannot be changed or removed. Anyone who knows it can edit this database.
