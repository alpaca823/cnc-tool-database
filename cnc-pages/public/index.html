Admin settings

Back up & move settings

Shop data saves to the shared database. Export JSON or download an offline snapshot. Imports replace inventory, libraries, cutting settings, notes, and the cut list for everyone.

Offline copies use admin / Feds201 in a fresh browser. Shared passwords stay in the database and are not included in exports. Offline copies do not sync automatically.

Admin passwords

All passwords use the username admin. The fallback password admin is always enabled and cannot be changed or removed. Anyone who knows it can edit this database.

Add admin password

Use 8–128 characters. Add up to 20 additional passwords. Changing or removing a password signs out sessions using that password.
